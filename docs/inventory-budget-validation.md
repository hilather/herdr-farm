# Inventory-budget hotfix validation

Validated in the hard sandbox on branch `factory/inventory-budget`, based on
`80b7d84`. All cargo commands used `TMPDIR=$PWD/target/tmp` and
`nice -n 19 ionice -c 3 cargo ... --locked --offline -j 3 --features state-store`.
No live project, server, ticker or owner agent data was accessed.

The fix retires terminated launch references only with release evidence,
preserves uncertain references, and raises the shared root record limit to
16,384 while retaining the 50 MiB and ten-second limits. Binding receipts match
the current generation. Exact-operation worktree recovery still reads history.
Schema 43's historical lifecycle cache remains unchanged; pane conflict reads
use indexed events so their effective eligibility agrees with root-wide reads.
No new crate, index, canonical migration, telemetry migration, backup category
or retention category is needed.

`cargo clippy --locked --offline -j 3 --features state-store --all-targets`
completed successfully. Existing warnings remain; none point to changed lines
or either new test file. `git diff --check` passed. Only the two new test files
were formatted directly with rustfmt; no repository-wide formatting was run.

The new E2E tests pass with 1,040 terminated/released launches across two
published projects, including launched bindings, targets, workspaces and creation
intents. They also exercise more than 1,024 unreleased bindings, live and uncertain
pane conflicts, record-budget diagnostics, and public-store adoption, relinquishment
and rebind behavior. Historical v1 inputs are seeded with their insertion guard
temporarily suspended inside the isolated fixture transaction and restored before
commit; no production schema is changed.

Two worker E2E cases initially failed during concurrent validation with a deadline
and a replaced binary. Both were rerun separately against a stable build and
reached only the forbidden fixture socket bind:

- `dedicated_worker_refuses_remote_manifest_before_its_brief`
- `editing_worker_requires_operator_completion_when_automation_is_off`

Socket-dependent coverage must be rerun by the steward outside this sandbox.
In particular, the extended coordinator `open --reprime` and launch-side worktree
preparation workflows could not reach their new history checks here. Direct bind
failures report `Operation not permitted`; worker fixture servers print Python
`PermissionError` and their tests time out waiting for the absent socket. Native
interaction fixtures similarly exit while trying to bind their probe server.
No socket workaround was attempted.

The three known `copy_jobs` tests affected by a TMPDIR inside a git checkout
were not part of these requested filtered suites and were not run or changed.
